# Project-4 (оптимизация с Redis)

Учебный демо-проект по оптимизации производительности при работе с базой данных с использованием Hibernate и кэширования в Redis.

## Цель проекта
Оптимизировать время выполнения частого запроса (получение города с информацией о стране и списком языков) путём выгрузки агрегированных данных в Redis.

### Демо-проект на базе базы данных world (MySQL)

- В реляционной БД данные хранятся в разных таблицах:
    - `City`
    - `Country`
    - `CountryLanguage`
- Технологический стек:
    - Java 17+
    - Maven
    - Hibernate (JPA 3)
    - MySQL 8
    - Redis 7
    - PGSpy (логирование SQL)
    - Docker / Docker Compose
    - JUnit 5 (тестирование)
    - Lombok
    - Jackson (JSON)

## Настройка переменных окружения
Хранение логина и пароля в переменных окружения.  
Требуется настроить значения `DB_PASSWORD`, `DB_USER`.

# Запуск окружкения
```bash
docker-compose up -d
```
# Чтобы остановить контейнеры 
```bash
docker-compose down
```
